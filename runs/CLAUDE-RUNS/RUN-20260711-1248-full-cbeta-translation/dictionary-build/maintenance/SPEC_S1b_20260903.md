## 2. Edit classes (this lane's complete set)

- `anchor-remove-dup` (391): `anchors.pop(aidx)`; if the list becomes empty,
  `del sense["ClaimAnchors"]` (A1 byte-shape).
- `anchor-remove-pointer` (83): same mechanical action; record carries the
  pointer/mirror evidence instead of the dup-holder evidence.

No other field of any entry changes. Both classes assert the anchor's
identity bytes (RelPath+ClaimText for standalone; OccurrenceIndex+ClaimText
for pointers) before removal, so any drift between census and live bytes
aborts the engine.
